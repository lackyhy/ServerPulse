# ⚡ ServerPulse — Панель мониторинга серверов

Современная система мониторинга удаленных серверов в реальном времени. Написана на **Rust** (Axum, Tokio) с веб-интерфейсом на **React**, **TypeScript** и **Vite**.

![ServerPulse Icon](frontend/public/favicon.svg)

---

## 📌 Разделение конфигурации

Конфигурация разделена на два логических файла:

1. **[`config.yaml`](config.yaml)** — системные параметры веб-панели (порт, хост, пароль входа, пути к файлам, SSH-ключ, таймауты).
2. **[`servers.yaml`](servers.yaml)** — список отслеживаемых серверов с их параметрами.

> 💡 **Hot-Reload**: изменение любого из этих файлов (`config.yaml` или `servers.yaml`) автоматически подхватывается на лету без необходимости перезапускать сервер!

---

## 🔒 Защита панели паролем

Вы можете ограничить доступ к веб-панели и REST API с помощью единого пароля администратора.

- **Настройка в [`config.yaml`](config.yaml):**
  ```yaml
  # Пароль для доступа к веб-панели и API
  password: 'my-super-secret-password'
  ```
- **Как это работает:**
  - При установленном пароле все вызовы API (`/api/servers`, `/api/server-metrics`, `/api/server-ports`, `/api/events` и т.д.) без правильного пароля возвращают **`403 Forbidden`**.
  - Веб-интерфейс автоматически отображает красивое окно авторизации с логотипом и вводом пароля.
  - Токен сохраняется в браузере (`localStorage`) и прикрепляется к заголовкам `Authorization: Bearer <пароль>` и SSE-подключениям.
  - В шапке дашборда появляется кнопка **«Выход»**.
  - Если пароль оставить пустым (`password: ''`) или закомментировать, панель работает в открытом режиме без запроса пароля.

## ⚙️ Где и как меняется порт?

### 1. Порт веб-интерфейса и REST API сервера ServerPulse
По умолчанию сервер слушает порт **`3000`**.

- **Основное место настройки:** в файле **[`config.yaml`](config.yaml)**:
  ```yaml
  # Порт веб-панели и REST API
  port: 3000

  # Хост привязки (0.0.0.0 — слушать на всех интерфейсах, 127.0.0.1 — только локально)
  host: "0.0.0.0"
  ```
- **Значение по умолчанию в коде Rust:** в файле **[`src/config.rs`](src/config.rs)**:
  ```rust
  fn default_listen_port() -> u16 {
      3000
  }
  ```
- **При запуске фронтенда в режиме разработки (`npm run dev`):**
  В файле **[`frontend/vite.config.ts`](frontend/vite.config.ts)**:
  - `server.port: 5173` — порт Vite Dev сервера.
  - `server.proxy['/api'].target: 'http://127.0.0.1:3000'` — адрес бэкенда, на который проксируются запросы `/api`. Если вы изменили `port` в `config.yaml`, обновите этот `target`.

---

### 2. Порты опрашиваемых удаленных серверов (SSH / TCP / HTTP)
Каждый удаленный сервер имеет свой индивидуальный порт подключения.

- **Где настраивается:** в файле **[`servers.yaml`](servers.yaml)**:
  ```yaml
  servers:
    - name: 'Web Server'
      host: '192.168.1.50'
      port: 80               # <- Порт подключения HTTP/сервиса
      check_type: 'http'
      interval_seconds: 10
      timeout_ms: 3000

    - name: 'Database Server'
      host: 'db.example.com'
      port: 22               # <- Порт SSH или БД
      check_type: 'tcp'
      interval_seconds: 10
      timeout_ms: 3000
  ```

## 🚀 Возможности

- 📊 **Мониторинг железа**: ЦП (нагрузка loadavg, % использования, количество ядер), ОЗУ (всего / свободно / занято), **Swap** (всего / свободно / занято / %), Диск (GB, %), Сеть (RX/TX трафик) и Uptime.
- 🐳 **Docker**: просмотр списка всех контейнеров, их статусов, образов и проброшенных портов.
- 💻 **tmux**: список активных сессий (окна, время создания, статус `attached` / `detached`).
- 🔌 **Порты (`ss -tulnp`)**:
  - Быстрый вывод всех слушающих сокетов.
  - Фильтры в один клик: **`[ Все ]` | `[ TCP ]` | `[ UDP ]`**.
  - Поиск по порту, названию процесса, PID и IP-адресу.
  - Определение области видимости (`0.0.0.0 / Публичный` vs `127.0.0.1 / Localhost`).
  - Быстрое копирование `хост:порт` в буфер обмена.
- ⚡ **Real-time SSE**: мгновенное обновление статусов через Server-Sent Events.
- 📈 **Спарклайны задержки**: история пинга/отклика по каждому узлу.

## 🛠️ Запуск проекта

### 1. Сборка веб-интерфейса (Frontend)
```bash
cd frontend
npm install
npm run build
cd ..
```

### 2. Запуск сервера (Backend)
```bash
cargo run
```
После запуска панель будет доступна по адресу:
👉 **`http://localhost:3000`** (или порту, заданному в `config.yaml`).

### Разработка фронтенда с Hot-Reload (Vite):
```bash
cd frontend
npm run dev
```
Фронтенд запустится на `http://localhost:5173` и будет проксировать API-запросы на бэкенд `http://127.0.0.1:3000`.
